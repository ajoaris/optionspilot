# optionspilot

Source of [optionspilot.ai](https://optionspilot.ai), built with GitHub Pages and Jekyll (minima theme).

## Adding content

Create a file in `_posts/` named `YYYY-MM-DD-short-title.md`, starting with:

```
---
layout: post
title: Your title
categories: journal
---
```

Use `categories: reports` for a periodic review. Results figures are edited directly in `results.md`.

GitHub rebuilds the site within a minute or two of each push.
